# PRD: LensNet Signed Routing Head for Expand/Collapse Decisions  
## Project: Multi‑LOD Long‑Context LLM with Dynamic WorkingContext  
### Component: Signed Expand/Collapse Routing via Mid‑Layer Gist–Tail Interaction

---

## 1. Overview

This PRD defines the **LensNet Signed Routing Head**, a lightweight module integrated into the **main transformer** that produces a single **signed scalar** per gist node:

> **score(g) ∈ [−1, +1]**  
> • **+1** = strongly expand (children are likely useful)  
> • **0** = keep as‑is  
> • **−1** = collapse (neither gist nor children help)

The score is computed using **only WorkingContext (WC)** information at inference. Training uses a **single forward pass** and derives targets from **actual attention** into each gist’s children when they are present.

LensNet becomes the **unified routing signal** for the Context Manager.

---

## 2. Key Insight

During inference, we know:
- **a)** how much the tail attends to a gist (`attn_tail→gist`)  
We want to predict:
- **b)** how much the tail *would* attend to the gist’s children **if they were expanded**.

During training, children are available, so we can measure **b** directly using attention.  
LensNet learns **f(a, h_tail, h_g, metadata) → b** and maps it into a signed score.

---

## 3. Goals

### 3.1 Functional Goals
- Provide a continuous **expand/collapse score** per gist.
- Learn child-utility prediction from:
  - `h_tail_mid`, `h_g_mid`
  - `attn_tail→g`
  - recency, LOD level
- Require only one forward pass for training.

### 3.2 Performance Goals
- O(WC_len) inference overhead.
- No MC traversal.
- No global scans.

---

## 4. Inputs & Outputs

### 4.1 Inputs
- `h_g_mid`, `h_tail_mid`
- `attn_tail_to_g`
- `level_emb`, `recency_emb`

### 4.2 Output
```
score(g) = tanh( MLP([h_g_mid, h_tail_mid, attn_tail_to_g, level_emb, recency_emb]) )
```

---

## 5. Training Target Construction

### 5.1 Compute subtree usage
```
u_child  = Σ A[L,h,q,k]   over k ∈ descendants S(g)
u_parent = Σ A[L,h,q,g]
mass     = u_child + u_parent
expandiness = u_child / (mass + ε)
```

### 5.2 Signed target
```
base = 2 * expandiness - 1         # [-1, +1]
g_mass = mass / (mass + c)
target = base * g_mass + (-1)*(1 - g_mass)
```

### 5.3 Loss
```
L_lens = Σ_g (score(g) - target(g))²
```

---

## 6. Inference Behavior

```
if score > τ_expand: expand
elif score < −τ_collapse: collapse (leaf only)
else: keep
```

---

## 7. Interaction With Context Manager

LensNet = primary router.  
Heuristics enforce must‑keep rules and WC length limits.
