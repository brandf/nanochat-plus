# Technical Design Document (TDD)
## Dynamic WorkingContext (WC) Manager for Long-Context LLM

---

## 1. Architecture Overview

The WC Manager is a **standalone component** that operates between:

- The **MegaContext (MC) storage** (on disk, random-access only).
- The **multi-LOD transformer model**, which consumes the in-memory WorkingContext (WC).

At each decode step, the manager:

1. Receives the current WC and attention maps from the last forward pass.
2. Computes per-node focus scores from WC-only information.
3. Applies a sequence of **expand** and **collapse** operations to maintain:
   - Valid tree structure.
   - Context size budget `WC_len`.
4. Produces an updated WC to be used at the next forward pass.

All logic is confined to WC and metadata; MC is accessed only via explicit child-load calls.

### 1.1 Implementations

Two concrete managers share the same façade:

- `TrainingContextManager` (TCM)
  - Owns an in-memory `MegaContextTree` and `WorkingContextTree`.
  - Builds the full tree for each batch in a single pass (using the shared `GistNet`), converts it into a fully populated WCT (`tree_causal_ordering=True`, `fully_virtual=True`), and applies *masked* sparsification masks (no physical omission).
  - Derives a deterministic holdout mask that captures the tail-induced subtree used for next-gist supervision; this mask composes with the sparsity mask before the forward pass.
  - Trains LensNet once implemented by computing attention-derived signed targets from `LensNet_Signed_*`.
- `InferenceContextManager` (ICM)
  - Owns persistent MCT/WCT instances across autoregressive steps.
  - Accepts new LOD0 embeddings each decode step, appends them to the MCT, mirrors newly minted latents into the WCT, and maintains the WCT size inside a configurable window via expand/collapse operations.
  - Until LensNet exists, it uses a deterministic seeded scorer that produces placeholder focus values in `[-1, +1]` while still honoring all WCT invariants (parents always persist when children are active, except for partial tail blocks).

Both implementations expose the same external API (`build_training_batch`, `step`, `refocus`, etc.) so higher-level code never manipulates MCT/WCT directly.

## 2. Data Structures

### 2.1 WCNode

```python
from dataclasses import dataclass
from typing import List, Optional
import torch

@dataclass
class WCNode:
    id: int                           # Underlying MC node ID
    level: int                        # LOD index (0 = tokens)
    mu: float                         # time coordinate (e.g. span center)
    sigma: float                      # scale / variance
    latent: torch.Tensor              # [d_model] contextualized vector
    parent: Optional[int]             # MC node ID of parent, or None
    has_children_in_MC: bool          # does MC store children for this node?
    children_in_WC: List[int]         # MC node IDs of children currently in WC
    is_must_keep: bool = False        # e.g. last K tokens, last per LOD
    focus: float = 0.0                # attention-derived importance score
```

Constraints:

- If `child_id` appears in `children_in_WC`, the parent’s `id` must also correspond to a node present in WC.
- The WCState module is responsible for maintaining this invariant.

### 2.2 MC Access Interface

We assume an abstract MC storage API:

```python
class MegaContextStore:
    def load_children(self, node_id: int) -> List[dict]:
        """Return metadata and latent for each child.
        Each element in the list should include:
        - 'id': int
        - 'level': int
        - 'mu': float
        - 'sigma': float
        - 'latent': torch.Tensor
        - 'has_children_in_MC': bool
        Parent relationships are implied by the caller.
        """
        ...
```

Implementation of MC storage (e.g. file formats, indices) is out of scope for this TDD.

## 3. WCState Module

### 3.1 Responsibilities

- Maintain the current WC as a collection of WCNode objects.
- Enforce invariants:
  - No child without parent.
  - Parents never removed when they have children in WC.
- Provide helper methods to:
  - Identify leaf nodes.
  - Identify candidates for expansion and collapse.
  - Track must-keep nodes and current size.

### 3.2 API Sketch

```python
class WCState:
    def __init__(self, nodes: List[WCNode]):
        self.nodes_by_id: Dict[int, WCNode] = {n.id: n for n in nodes}

    def current_size(self) -> int:
        return len(self.nodes_by_id)

    def get_node(self, node_id: int) -> WCNode:
        return self.nodes_by_id[node_id]

    def all_nodes(self) -> List[WCNode]:
        return list(self.nodes_by_id.values())

    def is_leaf(self, node_id: int) -> bool:
        return len(self.nodes_by_id[node_id].children_in_WC) == 0

    def eligible_for_expand(self, node_id: int) -> bool:
        n = self.nodes_by_id[node_id]
        return self.is_leaf(node_id) and n.has_children_in_MC

    def eligible_for_collapse(self, node_id: int) -> bool:
        n = self.nodes_by_id[node_id]
        return (
            self.is_leaf(node_id)
            and not n.is_must_keep
        )

    def add_child(self, parent_id: int, child: WCNode):
        self.nodes_by_id[child.id] = child
        self.nodes_by_id[parent_id].children_in_WC.append(child.id)

    def remove_node(self, node_id: int):
        # only remove leaves; caller must enforce invariants
        node = self.nodes_by_id[node_id]
        assert len(node.children_in_WC) == 0, "Cannot remove non-leaf node"
        # detach from parent
        if node.parent is not None and node.parent in self.nodes_by_id:
            parent = self.nodes_by_id[node.parent]
            parent.children_in_WC = [
                cid for cid in parent.children_in_WC if cid != node_id
            ]
        del self.nodes_by_id[node_id]
```

WCState does **not** know about attention or scores; it is purely structural.

## 4. FocusScorer Module

### 4.1 Responsibilities

- Compute per-node focus scores using only attention maps and node metadata in WC.
- Update the `focus` field on each WCNode.

### 4.2 Inputs

- `attention`: Tensor `[L, H, Q, K]` from the last forward pass.
  - Q and K indices correspond to WC nodes in the same flattened order used by the transformer.
- `wc_state`: WCState.
- `tail_query_indices`: List of indices in Q dimension considered “tail queries” (e.g. last 1–4 token nodes).
- Smoothing parameters (e.g. EMA factor).

### 4.3 Algorithm

1. Build a list that maps flattened transformer indices to WC node IDs.
   - This mapping is already needed by the base model; the context manager reuses it.

2. For each node (key index `k`):

   ```python
   I_k = mean_over_layers_heads_tail( attention[:, :, q_tail, k] )
   ```

3. Optionally apply EMA:

   ```python
   node.focus = alpha * node.focus + (1 - alpha) * I_k
   ```

4. Optionally scale or normalize focus by level or recency.

### 4.4 API Sketch

```python
class FocusScorer:
    def __init__(self, alpha: float = 0.9):
        self.alpha = alpha

    def update_focus(
        self,
        wc_state: WCState,
        attention: torch.Tensor,
        index_to_node_id: List[int],
        tail_query_indices: List[int],
    ):
        L, H, Q, K = attention.shape
        # Average attention from tail queries
        att = attention[:, :, tail_query_indices, :]  # [L, H, Q_tail, K]
        att_mean = att.mean(dim=(0, 1, 2))            # [K]

        for k, node_id in enumerate(index_to_node_id):
            node = wc_state.get_node(node_id)
            I_k = att_mean[k].item()
            node.focus = self.alpha * node.focus + (1 - self.alpha) * I_k
```

## 5. Expand/Collapse Policy

### 5.1 Scoring Functions

We define:

```python
def expand_score(node: WCNode) -> float: ...
def collapse_score(node: WCNode) -> float: ...
```

Initial POC formulas (heuristic):

- Let `recency = current_mu_tail - node.mu` (clamped to ≥ 0).
- Let `level = node.level`.

Example heuristics:

```python
def expand_score(node: WCNode, recency: float) -> float:
    # High focus, coarser level, not too recent
    return node.focus * (1 + level) / (1 + recency)

def collapse_score(node: WCNode, recency: float) -> float:
    # Low focus, fine level, not too recent
    inverse_focus = 1.0 / (1e-6 + node.focus)
    return inverse_focus * (1 + max_level - level) / (1 + recency)
```

These can be tuned or replaced by a future learned LensNet, but must:

- Only depend on WC node fields (`focus`, `level`, `mu`, `sigma`, etc.).
- Be computable in O(WC_len).

### 5.2 Expand Operation

- Preconditions:
  - `wc_state.eligible_for_expand(node_id)` is True.

- Steps:

  ```python
  children_meta = mc_store.load_children(node.id)
  # We may choose to:
  #  - load all children but only insert top-N by some heuristic, or
  #  - load only a subset by ID.
  # For POC we'll load all, but insert one at a time or all at once (configurable).
  ```

- For each child to insert:
  - Construct a WCNode from metadata.
  - `wc_state.add_child(parent_id=node.id, child=child_node)`.

- Note: parent stays in WC, now no longer a leaf.

### 5.3 Collapse Operation

- Preconditions:
  - `wc_state.eligible_for_collapse(node_id)` is True.

- Steps:

  ```python
  wc_state.remove_node(node_id)
  ```

- Parent remains; if this was the last child, parent may become a leaf and later be eligible for collapse (if not must-keep).

## 6. ContextManager Module

### 6.1 Responsibilities

- Orchestrate scoring and expand/collapse decisions.
- Enforce WC size budget and invariants.

### 6.2 API Layers

- **TrainingContextManager**
  - `build_batch(token_ids: torch.Tensor) -> Tuple[torch.Tensor, Dict]`
    - Embeds tokens, streams them into `MegaContextTree.append_lod0`, runs a full gist prefill, and produces a `WorkingContextTree` tensor bundle (`latents`, `node_ids`, `flags`, `lengths`) with `tree_causal_ordering=True`, `fully_virtual=True`.
    - Applies a deterministic (seeded) masked-drop mask (respecting must-keep rules) to simulate sparsity without physically omitting nodes, then composes it with a tail holdout mask that reserves the induced subtree needed for next-gist supervision. These masks replace any attention-dropout usage; the transformer should run with dropout probability zero so masking remains deterministic.
    - Returns metadata required by the transformer (index mappings, `mu/sigma` derivations), the combined sparsity/holdout masks, and any LensNet supervision tensors.
  - `train_lensnet(attention, node_metadata)` - optional hook that computes LensNet signed scores from the latest attention maps. Operates even though LensNet predictions are not used for selection yet.
- **InferenceContextManager**
  - `step(new_lod0: torch.Tensor) -> Tuple[torch.Tensor, Dict]`
    - Appends embeddings to the shared MCT (batch-synchronous), updates higher LODs incrementally, mirrors newly created latents into the WCT, and returns the flattened tensors required by the transformer.
  - `maybe_refocus(attention, index_to_node_id)` - checks whether the current WCT size lies outside the window `[target_node_count - target_node_shrink, target_node_count + target_node_growth]`. If so, it invokes the expand/collapse policy (Section 5) using seeded placeholder scores that only rank eligible leaves (ancestor invariants still gate all operations) until LensNet is ready.
  - `force_refocus(reason: str)` - utility for callers (e.g., KV repair) to trigger a manual expand/collapse cycle.

Both implementations reuse the shared helper methods described below.

### 6.3 API Sketch

```python
class ContextManager:
    def __init__(
        self,
        wc_len: int,
        tail_token_keep: int,
        max_expand_per_step: int = 16,
        max_collapse_per_step: int = 16,
    ):
        self.wc_len = wc_len
        self.tail_token_keep = tail_token_keep
        self.max_expand_per_step = max_expand_per_step
        self.max_collapse_per_step = max_collapse_per_step
        self.focus_scorer = FocusScorer()

    def update(
        self,
        wc_state: WCState,
        attention: torch.Tensor,
        index_to_node_id: List[int],
        tail_query_indices: List[int],
        mc_store: MegaContextStore,
    ) -> List[dict]:
        """Update WC in place and return an operation log."""
        ops = []

        # 1) Update focus scores
        self.focus_scorer.update_focus(
            wc_state, attention, index_to_node_id, tail_query_indices
        )

        # 2) Mark must-keep nodes (e.g. tail tokens, last per level)
        self._mark_must_keep(wc_state, index_to_node_id)

        # 3) Collapse if over budget
        ops.extend(self._collapse_until_budget(wc_state))

        # 4) Expand if below budget and beneficial
        ops.extend(self._expand_while_beneficial(wc_state, mc_store))

        return ops
```

### 6.4 Budget Logic (Collapse)

```python
def _collapse_until_budget(self, wc_state: WCState) -> List[dict]:
    ops = []
    if wc_state.current_size() <= self.wc_len:
        return ops

    # Collect collapse candidates
    candidates = [
        n for n in wc_state.all_nodes()
        if wc_state.eligible_for_collapse(n.id)
    ]

    # Sort by collapse_score descending
    candidates.sort(
        key=lambda n: collapse_score(
            n, recency=self._compute_recency(n)
        ),
        reverse=True,
    )

    for node in candidates:
        if wc_state.current_size() <= self.wc_len:
            break
        wc_state.remove_node(node.id)
        ops.append({"op": "collapse", "node_id": node.id})
        if len(ops) >= self.max_collapse_per_step:
            break

    return ops
```

### 6.5 Expansion Logic

```python
def _expand_while_beneficial(
    self, wc_state: WCState, mc_store: MegaContextStore
) -> List[dict]:
    ops = []
    # Collect expansion candidates (leaves with children)
    candidates = [
        n for n in wc_state.all_nodes()
        if wc_state.eligible_for_expand(n.id)
    ]

    # Sort by expand_score descending
    candidates.sort(
        key=lambda n: expand_score(
            n, recency=self._compute_recency(n)
        ),
        reverse=True,
    )

    for node in candidates:
        if wc_state.current_size() >= self.wc_len:
            break

        children_meta = mc_store.load_children(node.id)
        if not children_meta:
            continue

        # For POC: expand one child at a time (e.g. first or random)
        child_info = children_meta[0]
        child = WCNode(
            id=child_info["id"],
            level=child_info["level"],
            mu=child_info["mu"],
            sigma=child_info["sigma"],
            latent=child_info["latent"],
            parent=node.id,
            has_children_in_MC=child_info["has_children_in_MC"],
            children_in_WC=[],
        )
        wc_state.add_child(node.id, child)
        ops.append({"op": "expand", "parent_id": node.id, "child_id": child.id})

        if len(ops) >= self.max_expand_per_step:
            break

    return ops
```

## 7. Testing Plan

### 7.1 Unit Tests

#### WCState

- **Test add/remove invariants**:
  - Adding a child attaches it to the parent.
  - Removing a node updates the parent’s `children_in_WC` list.
  - Removing a non-leaf raises an assertion.

- **Test `eligible_for_expand`**:
  - Returns True only for leaf nodes with `has_children_in_MC=True`.

- **Test `eligible_for_collapse`**:
  - Returns False for must-keep nodes.
  - Returns False for non-leaf nodes.

#### FocusScorer

- **Test shape handling**:
  - Given random attention `[L, H, Q, K]` and mapping `index_to_node_id`,
    ensure focus is assigned to all nodes without errors.

- **Test tail dependence**:
  - If all attention mass from tail goes to a single key index, that node’s focus becomes largest.

- **Test EMA**:
  - After multiple calls, focus tracks a smoothed average.

#### ContextManager

- **Test collapse-only**:
  - With WC larger than budget and no expand candidates,
    confirm that collapse operations are applied until size ≤ WC_len.

- **Test expand-only**:
  - With WC smaller than budget and valid expand candidates,
    confirm that expansions add children and parents are preserved.

- **Test must-keep enforcement**:
  - Mark some nodes as must-keep and verify they are never removed.

### 7.2 Integration Tests

#### Synthetic Tree Scenario

1. Create a tiny MC with:
   - 8 tokens, 4 LOD1 gists, 2 LOD2 gists.
2. Initialize WC to include:
   - All LOD2, some LOD1, and some tokens.
3. Simulate attention where:
   - Tail tokens attend strongly to one LOD2 gist.
4. Run ContextManager update with:
   - Sufficient budget to expand.
5. Verify:
   - Children of the attended gist are loaded and added to WC.
   - Parents remain in WC.

#### Rolling Decode Simulation

- Simulate N decode steps with random but structured attention maps.
- At each step:
  - Run ContextManager update.
  - Assert WC size remains within budget.
  - Log operations and manually check a few sequences for invariant violations.

## 8. Future Extensions

- **LensNet Integration**:
  - Replace heuristic expand/collapse scores with a small learned MLP that takes node features (latent, focus, level, recency).
  - Train LensNet via local A/B experiments or teacher distillation.

- **Smarter Child Selection**:
  - Instead of always picking the first child, rank children by a cheap heuristic (e.g., approximated importance from parent’s focus and span geometry).

- **Multi-child Expansion and Region-Based Policies**:
  - Expand multiple children when the focus score is very high and budget permits.
  - Collapse entire low-focus subtrees by repeated leaf collapses.

This TDD is intended to be concrete enough for a coding agent to implement a functioning WC Manager that obeys all invariants and constraints, while still being simple and extensible.
