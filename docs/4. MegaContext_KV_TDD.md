# MegaContext KV Caching - Technical Design Document (TDD)

This TDD describes concrete data structures and algorithms for the two KV caching strategies:
- Option 1: Dirty-Suffix Prefill (time-sorted WC)
- Option 3: Append-Only + Window Recompute (append-only WC)

All content is ASCII-safe.

---

## 1. Data Structures

### 1.1 Node Identifiers

Assume each MC node has a unique integer NodeID.

```python
NodeID = int
```

### 1.2 KVSlot

Represents cached K/V for a single WC node.

```python
class KVSlot:
    def __init__(self, node_id: NodeID, num_layers: int, num_heads: int, head_dim: int):
        self.active: bool = True
        self.node_id: NodeID = node_id
        # K[layer] and V[layer] are tensors of shape [num_heads, head_dim]
        self.K = [None] * num_layers
        self.V = [None] * num_layers
```

### 1.3 KVCache

```python
class KVCache:
    def __init__(self, num_layers: int, num_heads: int, head_dim: int):
        self.num_layers = num_layers
        self.num_heads = num_heads
        self.head_dim = head_dim
        self.slots: list[KVSlot] = []
        self.free_slots: list[int] = []  # used in Option 3

    def allocate_slot(self, node_id: NodeID) -> int:
        if self.free_slots:
            idx = self.free_slots.pop()
            slot = self.slots[idx]
            slot.active = True
            slot.node_id = node_id
            return idx
        else:
            idx = len(self.slots)
            self.slots.append(KVSlot(node_id, self.num_layers, self.num_heads, self.head_dim))
            return idx

    def free_slot(self, idx: int):
        self.slots[idx].active = False
        self.free_slots.append(idx)
```

### 1.4 WC Serialization

Option 1 (time-sorted):

```python
wc_nodes: list[NodeID]  # always sorted by mu
```

Option 3 (append-only):

```python
wc_slots: list[int]  # list of KV slot indices, append-only
```

## 3. Option 1 - Dirty-Suffix Prefill

### 3.1 WC update

```python
class DirtySuffixStrategy(KVStrategy):
    def __init__(self, kv_cache: KVCache, wc_nodes: list[NodeID]):
        self.kv = kv_cache
        self.wc_nodes = wc_nodes

    def on_focus_step(self, expansions: list[NodeID], collapses: list[NodeID]):
        # 1) Apply collapses
        dirty_indices = []

        for node in collapses:
            if node in self.wc_nodes:
                idx = self.wc_nodes.index(node)
                self.wc_nodes.pop(idx)
                dirty_indices.append(idx)

        # 2) Apply expansions (children insert by mu)
        for g in expansions:
            children = load_children_from_mc(g)  # returns list[(child_id, mu)]
            children_sorted = sorted(children, key=lambda x: x[1])
            for child_id, mu in children_sorted:
                insert_idx = find_insert_position_by_mu(self.wc_nodes, child_id, mu)
                self.wc_nodes.insert(insert_idx, child_id)
                dirty_indices.append(insert_idx)

        if not dirty_indices:
            return  # nothing changed

        i_min = min(dirty_indices)
        self._recompute_suffix(i_min)
```

### 3.2 Recompute suffix

```python
    def _recompute_suffix(self, i_min: int):
        # For simplicity, we assume we recompute all layers in one pass.
        # In practice you may want a more efficient batched implementation.
        for j in range(i_min, len(self.wc_nodes)):
            node_id = self.wc_nodes[j]
            slot_idx = j  # one slot per position for this mode
            # ensure slot exists
            if slot_idx >= len(self.kv.slots):
                self.kv.allocate_slot(node_id)
            else:
                self.kv.slots[slot_idx].node_id = node_id
                self.kv.slots[slot_idx].active = True
            for layer in range(self.kv.num_layers):
                K_j, V_j = forward_single_position(layer, slot_idx, self.kv, self.wc_nodes, build_masks)
                self.kv.slots[slot_idx].K[layer] = K_j
                self.kv.slots[slot_idx].V[layer] = V_j
```

## 4. Option 3 - Append-Only + Window Recompute

### 4.1 WC update

```python
class AppendWindowStrategy(KVStrategy):
    def __init__(self, kv_cache: KVCache, wc_slots: list[int], window_size: int):
        self.kv = kv_cache
        self.wc_slots = wc_slots
        self.window_size = window_size

    def on_focus_step(self, expansions: list[NodeID], collapses: list[NodeID]):
        # 1) Collapses: mark slots inactive
        for node in collapses:
            for idx, slot_idx in enumerate(self.wc_slots):
                if self.kv.slots[slot_idx].node_id == node and self.kv.slots[slot_idx].active:
                    self.kv.free_slot(slot_idx)
                    # we can keep slot_idx in wc_slots, but marked inactive
                    break

        # 2) Expansions: append children slots
        new_slots = []
        for g in expansions:
            children = load_children_from_mc(g)  # returns list[child_id]
            for child_id in children:
                slot_idx = self.kv.allocate_slot(child_id)
                self.wc_slots.append(slot_idx)
                new_slots.append(slot_idx)
                # compute KV for child
                for layer in range(self.kv.num_layers):
                    K_j, V_j = forward_single_position(layer, slot_idx, self.kv, self.wc_slots, build_masks)
                    self.kv.slots[slot_idx].K[layer] = K_j
                    self.kv.slots[slot_idx].V[layer] = V_j

        # 3) Recompute tail window so recent nodes can see new children
        if self.window_size > 0:
            self._recompute_tail_window()
```

### 4.2 Tail window recompute

```python
    def _recompute_tail_window(self):
        if not self.wc_slots:
            return
        window_slots = self.wc_slots[-self.window_size:]
        # Clear K/V for window
        for slot_idx in window_slots:
            for layer in range(self.kv.num_layers):
                self.kv.slots[slot_idx].K[layer] = None
                self.kv.slots[slot_idx].V[layer] = None
        # Recompute K/V
        for slot_idx in window_slots:
            for layer in range(self.kv.num_layers):
                K_j, V_j = forward_single_position(layer, slot_idx, self.kv, self.wc_slots, build_masks)
                self.kv.slots[slot_idx].K[layer] = K_j
                self.kv.slots[slot_idx].V[layer] = V_j
```

## 5. Attention Mask Construction

The mask builder must:

- For Option 1:
  - Use WC index j and k plus mu(j), mu(k) to enforce that j only attends to earlier time and index.
- For Option 3:
  - Ignore index ordering for time.
  - Use mu(j) >= mu(k) to enforce temporal causality.
  - Still allow LOD-specific constraints as needed.

The exact mask function `build_masks` is assumed to be provided by the main model implementation and is not detailed here.

## 6. Testing Strategy

1. **Equivalence to full prefill**  
   - Fix a WC, run full prefill KV, then run incremental updates from a known baseline.
   - Ensure logits at the tail position match within tolerance.

2. **Stress tests with random expansions/collapses**  
   - Randomly modify WC many times.
   - Ensure no crashes and KV indices remain in bounds.

3. **Performance benchmarks**  
   - Measure wall-clock time per focus cycle for both strategies with realistic WC sizes.
   - Verify that dirty-suffix and window recompute are significantly cheaper than full prefill.

4. **Integration with LensNet**  
   - Ensure that focus cycles triggered by LensNet do not break decoding loops.
