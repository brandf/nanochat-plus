## 2. Module Definition

```python
class LensNetRoutingHead(nn.Module):
    def __init__(self, d_model, d_meta=32, d_hidden=256):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(2*d_model + 1 + d_meta, d_hidden),
            nn.ReLU(),
            nn.Linear(d_hidden, 1),
            nn.Tanh()
        )

    def forward(self, h_g, h_tail, attn_scalar, level_emb, recency_emb):
        meta = torch.cat([level_emb, recency_emb], dim=-1)
        x = torch.cat([h_g, h_tail, attn_scalar.unsqueeze(-1), meta], dim=-1)
        return self.mlp(x)
```

## 3. Target Computation

For each gist `g`:

### 3.1 Subtree usage
```
u_child  = attention.sum(q, S(g))
u_parent = attention.sum(q, g)
mass     = u_child + u_parent
expandiness = u_child / (mass + eps)
```

### 3.2 Signed target
```
base = 2*expandiness - 1
g_mass = mass / (mass + c)
target = base*g_mass + (-1)*(1 - g_mass)
```

### 3.3 Loss
```
L_lens += (score - target)**2
```
